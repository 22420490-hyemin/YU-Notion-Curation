# 📌 Y-Curation (영남대 공지 AI 큐레이션 시스템)

> **영남대학교의 다양한 게시판에 흩어진 공지사항을 통합 수집하고, LLM(대형 언어 모델)을 활용해 핵심 내용을 3줄로 요약 및 개인 맞춤형 키워드 매칭 알림을 제공하는 오픈소스 기반 시스템입니다.**


---


## 💻 How to Run (배포 및 실행 방법)

본 프로그램은 **실행 환경에 독립적(Independent)**으로 구동되도록 윈도우용 JRE(Java Runtime Environment) 엔진과 배포용 `.exe` 파일이 포함된 패키지 형태로 빌드되었습니다. 채점 환경 PC에 Java가 설치되어 있지 않더라도 완벽하게 독립 구동됩니다.

1. 배포된 **`Y-Curation.zip`** 압축 파일을 해제합니다.
2. 폴더 내 최상위에 위치한 **`Y-Curation.exe`**를 더블클릭하여 실행합니다.

### ⚠️ 시연 및 실행 시 주의사항
* **[시연 팁]** 로그인 화면에서는 별도의 회원가입 절차 없이, 임의의 학번과 비밀번호를 입력창에 채워 넣으시면 즉시 메인 피드로 진입하여 테스트가 가능합니다. *(※ 단, 빈칸으로 로그인 시 진입이 거부됩니다.)*
* 프로그램이 정상 작동하려면 실행 파일(`Y-Curation.exe`)과 동일한 폴더 내에 **`jre/`** 폴더(자바 가상머신 엔진) 및 **`config.txt`** (OpenAI API 설정 파일)가 반드시 같은 디렉토리에 존재해야 합니다.

## 🚀 Key Features (주요 기능 설명)
1. **학번 기반 간이 인증 및 로그인 (`UC-01`)**
   * 시연 가이드를 포함한 깔끔하고 모던한 UI 구현 및 빈칸 진입 방지 예외 처리.
2. **개인화된 키워드 설정 및 관리 (`UC-02`, `UC-03`)**
   * 사용자가 관심 있는 특정 키워드(예: 장학, 공모전 등)를 동적으로 등록 및 삭제하여 스팸성 정보 차단.
3. **LLM 기반 AI 3줄 요약 피드 (`UC-06`, `UC-09`)**
   * 가로 스크롤바가 없는 깔끔한 카드 레이아웃 피드를 통해 AI가 요약한 핵심 공지사항을 한눈에 가독성 있게 제공.
4. **학교 홈페이지 원문 리다이렉트 (`UC-10`)**
   * 요약본 확인 후 상세 행정 처리를 위해 영남대 공식 공지사항 페이지로 안전하게 바로 이동하는 연결 고리 제공.


---


## 🛠️ Tech Stack (사용 기술)
* **Language:** Java 17
* **Framework/Library:** Java Swing (GUI)
* **AI Engine:** OpenAI API (GPT 기반 공지사항 3줄 요약)
* **Data Processing:** Regular Expression 기반 키워드 매칭 로직
