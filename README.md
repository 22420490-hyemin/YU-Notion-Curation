## 1. Business purpose

### 1.1 Project Background & Motivation
현재 영남대 홈페이지 공지사항은 여러 게시판에 분산되어 있어 학생들이 매번 수동으로 확인해야 하는 번거로움이 있습니다. 이를 자동화하여 정보 불균형을 해소하고 학업 효율성을 높이고자 합니다.

### 1.2 Goal
Java 기반 크롤러와 AI 요약 엔진을 결합하여 맞춤형 공지 알림 서비스를 구축하는 것이 목표입니다.

### 1.3 Target Market
영남대학교 재학생 및 휴학생 전체가 대상입니다.
